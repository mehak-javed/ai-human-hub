# AI Human Hub: frontend

Next.js (App Router) + TypeScript client for AI Human Hub.

## Run locally

1. Copy the environment file: `cp .env.example .env.local`
2. Install dependencies: `npm install`
3. Start the backend (see `../backend`), then run: `npm run dev`
4. Open http://localhost:3000

## Scripts

- `npm run dev`: development server
- `npm run lint`: ESLint
- `npm run build`: production build (includes type-checking)
